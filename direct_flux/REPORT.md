对应设计文档：[`paper.md`](paper.md)。
实现：`src/simulation/controller/observer/direct_flux_observer.rs`。
状态：项目里**唯一**的磁链圆观测器；旧的 `flux_circle_observer.rs` 与
`kasa_flux_observer.rs` 已删除，拟合核心搬到 `direct_flux_observer.rs` 的前半部分。

## 1. 文件与代码结构

`direct_flux_observer.rs` 现在包含两半，只服务同一个观测器：

1. **流式拟合核心**
   - `V2` / `S` / `wrap_pi`；
   - `Moments`：36 个指数遗忘加权矩（`Σw`、`ΣwU`、`ΣwV`、`ΣwUUᵀ`、`ΣwUVᵀ`、
     `ΣwVVᵀ`、`Σwα`、…、`Σwγ²`）；
   - `Coef` / `Profile` / `fit_from_coef` / `fit_with_penalty_coef`：变量投影；
   - `FitConfig` / `Tracker` / `Report`：遗忘、最新样本搬原点、半径罚项、
     可观性指数、门限与 Newton。
2. **直接观测器**
   - `FastFlux`：快速环的 `∫s0`、`∫i`、相对圆心 `c`、`R`、半径、测速；
   - `DirectFluxObserver`：双速率调度、锁内交班、`Observer<3>` 实现。

`mod.rs` 只保留 `pub mod direct_flux_observer;`；`example1` 的
`use_observer = 12` 就是它。

## 2. 模型

零矢量期间（端电压为零）的电流斜率记为 `s0 = di/dt|v=0`，令

```text
A(t) = ∫ s0 dt ,   B(t) = ∫ i dt ,   k = R = Rs / L ,   p(k) = A + k B
```

由 `s0 = -(Rs i + ω × λ) / L` 得

```text
p(R) = A + R B = -(λ(t) - λ(0)) / L
```

即 `p(R)` 落在圆心 `c = λ(0)/L`、半径 `ρ = ψf/L` 的圆上。相位就是电角度：

```text
θ = atan2(-(p - c).y, -(p - c).x)
```

## 3. 流式拟合核心

### 3.1 36 个矩与变量投影

窗口被精确压缩成 36 个与 `k` 无关的加权矩，指数遗忘

```text
Σw ← ρ Σw + q ,   ΣwU ← ρ ΣwU + q U ,   …
```

其中 `q = (slope_dt/Δt)²`（零矢量越长越可信）。Kåsa 法方程写成

```text
J(k, θ) = θᵀ A(k) θ + 2 θᵀ b(k) + c(k)
A(k) = A0 + k A1 + k² A2
b(k) = b0 + k b1 + k² b2 + k³ b3
c(k) = c0 + k c1 + k² c2 + k³ c3 + k⁴ c4
```

固定 `k` 时有闭式 `θ*(k) = -A(k)⁻¹ b(k)` 和剖面

```text
P(k) = c(k) - b(k)ᵀ A(k)⁻¹ b(k)
```

`P'`、`P''` 都用解析式（不是差分）。每个拟合样本做一次带线搜索的 Newton。

### 3.2 半径伪观测

半径的允许范围写成对 `θ` 的线性化伪观测 `μ (gᵀθ - z)²`，越界时把
`μggᵀ`、`-μzg`、`μz²` 加进 `A0/b0/c0`。于是 `P`、`P'`、`P''` 一起变成
**带罚项**的剖面，Newton 步、回溯线搜索、输出都用同一个目标；报告的
`loss` / `sigma_rel` 仍用约束后 `θ` 上的**无罚项**残差，罚项常数不会污染
噪声门限。

### 3.3 最新样本搬原点

- 每个样本都做两次精确平移，把**最新样本**搬到原点：`U → U - u`、`V → V - v`；
  `off` 同时累加 `u` 和被 `k` 加权的 `v`（`V` 的平移在 `κ = k` 处等价于帧平移
  `k·v`），于是 `Report.center = c + off` 仍在物理圆心附近（`k` 恒定时精确，
  `k` 变化时残差 `Σ(k_i − k)·v_i`）；`update` 与 `step_once` 走同一条路径；
- `V` **不保存偏置**：给所有 `V_n` 加同一个常向量 `c` 只是把每个 `κ` 的点集
  平移 `κc`，`P`、`P'`、`P''`、`k`、半径都不变，所以拟合与 `V` 偏置无关；
- **不再用补偿求和**：`u`、`v` 每个拟合周期清零、只累加一次增量，长积分在
  `off` 里；去掉 Neumaier 累加器后 4 组工况输出逐位不变。

### 3.4 为什么不再需要剪切

矩里存原始 `U`、`V`，在 `κ = k` 处把 `b` 展开到三次、`c` 到四次
（`b3 = [g_vx, g_vy, 0]`、`c3 = 4b_g`、`c4 = g2`，都是已有矩）。直接观测器
每个拟合周期都把最新样本搬到原点，矩里的 `|U|`、`|V|` 只有“一个周期内增量”
的量级；拟合就在这个“最新样本为原点”的坐标系里求值，不做任何大数平移，
所以 `κ = k` 处没有论文 §6.1 那种大数相消。旧的剪切代码和 `--shear` 已删除
（A/B 见 §7.1）。

## 4. 直接观测器

### 4.1 双速率

| 环 | 频率 | 做什么 |
|---|---|---|
| 快速环 | 20 kHz（每次 `update`） | `∫s0`、`∫i`、`atan2`、一阶低通测速 |
| 低速环 | 每 `fit_period`（默认 10 ms） | 取一次积分增量、更新 36 矩、一次 Newton、交班 |

### 4.2 加锁交班

`FastFlux` 在 `Arc<Mutex<...>>` 里。到拟合时刻，在**同一把锁**内：

1. 取走 `a`、`b`、`q` 并清零；
2. `c += a + k_cur·b`（磁链 `c + a + k b` 严格连续）；
3. 锁外跑 `Tracker::step_once`；
4. 锁内把 `c`、`k`、`rad` 向目标滑动。三者的权重**不同**：

```text
c   ← c   + sync_gain·(c_tgt   - c)
k   ← k   + sync_gain·w_obs·(k_fit   - k)      w_obs = clamp(obs/obs_min, 0, 1)
rad ← rad + sync_gain·(rad_fit - rad)
```

`c_tgt = -(p_newest - c_fit) = -c_local`。最新样本的局部 `U`、`V` 已清零，而
`V` 不保存偏置，所以拟合给的圆心本身就是“相对最新样本”的圆心，`c_local = c`。

`R` 的交接乘可辨识性：稳态 `obs→0` 时不把拟合 `k` 的噪声游走带进快速环。
圆心/半径**不乘** `obs`——`obs` 描述的是 `k` 能不能被辨识，不是圆心/半径的
估计质量。也不能反过来按 `|k_fit − k_fast|` 冻结圆心：R 还没收敛时，用拟合的
`k` 算出的圆心恰好是把快速环拉向更准的圆，冻结会让启动瞬态更偏（实测 800 rad/s、
R 初值 0.5× 时启动 RMS 从 60° 变 76°，磁链中心瞬态偏移从 6.6 A 变 14 A）。
默认 `sync_gain = 0.05`，约 20 个拟合周期（200 ms）收敛。

### 4.3 角度与测速

```text
rel = c + a + k b ,   θ = atan2(-rel.y, -rel.x)
ω   = LPF(Δθ/Δt) ,    speed_tau = 20 ms
```

没有 PLL。上一版 PLL 在加速/减速时会因 `ω̇/wn²` 的稳态滞后把角度拖出几 rad，
直接反正切没有这个滞后；代价是角度噪声就是原始反正切噪声。

## 5. 门限与权重

直接观测器**不做硬冻结**，所有门限先做权重，乘在 Newton 步长上：

```text
w_obs   = clamp(|obs| / obs_min, 0, 1)²
w_sigma = clamp((σ_max / σ_rel)², 0, 1)
w_sig   = δ² / (δ² + σ_k²)
σ_k     = sqrt(2P / ((N_eff - 3) P''))
N_eff   = (Σw)² / Σw²
step    = raw_step · w_obs · w_sig · w_sigma
```

其中 `obs = P'' / (4R²Σw|V|²)`，`σ_rel` 是径向残差 RMS / 半径。
`k_sigma`（`|δ| < k_sigma·σ_k` 时跳过）和 `gate_sigma_rel` 是**可选**的硬门限，
默认关；打开时软权重仍然相乘。

## 7. 实测

命令：

```powershell
cargo run --release --example example1 -- --headless --observe-only `
  --seconds 8 --speed 100 --current-noise 0.001
```

`--observe-only` 下电流环仍用传感器角，观测器只做旁观；角度误差是电角度。

| 场景 | 角度 RMS | `R` | 半径 |
|---|---|---|---|
| 100 rad/s, 1 mA, 8 s | 1.327° | 433.67 (+12.92%) | 3.9919 (−1.25%) |
| 20 rad/s, 1 mA, 8 s | 1.568° | 406.04 (+5.73%) | 3.9863 (−1.39%) |
| 5 rad/s, 10 mA, 6 s | 18.0° | 539.7 (+40.5%) | 3.4241 (−15.30%) |
| 0.5 rad/s, 10 mA, 负载 0.5, 5 s | 65.3° | 383.48 (−0.14%) | 1.2869 |
| 闭环 20→100→5 rad/s, 1 mA, 8 s | 1.634° | 385.46 (+0.37%) | 4.0204 (−0.55%) |

角度误差可以分成两部分（详见 §9.1）：

- **确定性偏置**：无噪声时稳态误差是常数 `ω·Δt/2`（100 rad/s、Δt=50 µs 时
  0.1475°，20 rad/s 时 0.0306°），来自快速环的矩形积分（采样在区间末端，
  等效把磁链多推了半个控制周期）。这是当前实现的已知偏差，未做补偿。
- **噪声**：RMS 由零矢量斜率噪声积分出的磁链/圆心误差决定，在旋转坐标里
  表现为电频率附近的窄带分量。关掉斜率噪声（只留 1 mA 电流噪声）时 RMS 降到
  0.014°；斜率噪声 ×10 时 RMS 15.6°，且电频率分量从 0.04° 涨到 7.9°。

注意 1 mA 稳态两行的 `R`：去掉 `v_off` 后可观性尺度变成与 `V` 偏置无关的
`Σw|V|²`（存储坐标系），`obs` 比旧实现大约 600 倍，`R` 会在稳态噪声上游走
（100 rad/s 跑 30 s 到 −5.2%）。旧实现的 +0.03% 是因为 `v_off` 让 `obs≈5e-4`
把 `k` 近似冻结在初值。角度几乎不受影响（`R` 只给 `k·b` 定标，`b` 是 10 ms
内的电流积分）。

10 mA 下 `R` 会被噪声推走（5 rad/s 表里 +40%）：`obs` 分不清相干激励和噪声
曲率，这是“只按可观性加权”的直接后果，也是 `--k-sigma` / `--hard-sigma`
保留的原因。

### 7.1 剪切 / 补偿求和 / 二次平移的 A/B

| 改动 | 结果 |
|---|---|
| 剪切（保留开关但默认关）→ 删除整条路径 | 4 组工况的 `steady`、`observer` 行逐位一致 |
| Neumaier 补偿求和 → 普通 `V2` 累加 | 同上，逐位一致 |
| `step_once` 末尾的第二次 `recenter_latest` → 删除 | 同上，逐位一致（无剪切时 Newton 不碰 `u`、`v`，第二次平移本来就是空操作） |

唯一有非零差异的是更早的剪切开关对照（0.5 rad/s、10 mA、负载 0.5）：
`shear=true` 65.341° / 383.470 / 1.2869，`shear=false` 65.335° / 383.467 /
1.2873，属于舍入量级。0.5~100 rad/s、1~10 mA、`fit_period` 放大到 0.2 s 的
其余工况都逐位一致。

结论：这套“每拍把最新样本搬到原点”的结构里，剪切、补偿求和、第二次平移都是
冗余的，已全部删除。

### 7.2 平移 vs 拟合的开销

release 构建、单次调用：

| 操作 | 时间 |
|---|---|
| `translate_u` + `translate_v` | ~60 ns |
| 36 矩 `add` | ~15 ns |
| `coef_at` + `fit_from_coef` | ~120 ns |

平移发生在 10 ms 一次的拟合里，约占该周期的 `6×10⁻⁶`；合并 `translate_u` 和
`translate_v` 最多省一半，换不来可测量的收益，却要把两组精确变换合成一个带
`s·t` 交叉项的大公式，风险大于收益。因此保留两条独立的精确平移。

## 9. 局限

1. **`R` 只在瞬态可辨识**：恒 `iq`/`ω` 时 `P(k) ≡ 0`；1 mA 下 `obs` 仍可能
   足够大，`R` 会被噪声推动（见 §7 的表注），10 mA 下更明显。
2. **角度噪声就是原始反正切噪声**：没有 PLL 的低通，10 mA 下 ~17° 是物理
   SNR 限制，不是拟合问题。稳态的"周期性波动"是斜率噪声的旋转投影，见 §9.1。
3. **V 的斜坡去不掉**：`V` 的最新样本归零只去掉常数偏置；电流采样直流偏置
   积分出的斜坡仍会改变 `P(k)`，需要前端去偏置或带泄漏积分。
4. **斜率仍是 ODE 合成**：功率桥是平均模型，没有真实 PWM 双采样，这一局限
   继承自 `example1`。

### 9.1 稳态角度误差的来源

在 100 rad/s、1 mA 下把误差分解（dump 每拍 `err` 后做 FFT / 按真角度分箱）：

| 配置 | 误差 RMS | 电频率分量（15.9 Hz） | 结论 |
|---|---|---|---|
| 无噪声 | 0.006° | 0.002° | 只有恒定偏置 +0.1475° |
| 仅 1 mA 电流噪声（关斜率噪声） | 0.014° | 0.001° | 电流采样几乎不计入角度 |
| 1 mA（斜率噪声 ×1） | 1.32° | 0.75° | 斜率噪声主导 |
| 斜率噪声 ×10 | 15.6° | 7.9° | 与斜率噪声成正比 |

1. **确定性偏置 `ω·Δt/2`**：快速环用"当前样本 × Δt"做矩形积分。采样在
   区间末端，等于把磁链多推了半个控制周期，角度超前的量就是 `ω·Δt/2`
   （100 rad/s、50 µs → 0.143°；实测 0.1475°，20 rad/s 0.0306°）。
   对照实验：临时改成梯形积分 `(s_{k-1}+s_k)/2` 后偏置降到 0.004° / 0.002°，
   证实了来源；该改动已按要求回退，当前代码仍是矩形积分、保留这个已知偏置。
2. **电频率附近的"周期性波动"是噪声的旋转投影**。角度误差来自磁链估计的
   偏差向量 `δp`：`δθ ≈ (δp × n)/ρ`。`δp` 由零矢量斜率噪声积分而来，是
   相关时间 ~拟合窗/同步时间的慢变量；`n` 以电频率旋转，于是 `δθ` 在
   电频率处出现窄带分量、并带因转速/噪声起伏产生的边带。噪声为零时该分量
   只剩 0.002°。
3. **噪声量级与传感器模型自洽**。斜率噪声
   `σ_s = √2·σ_i/slope_dt ≈ 24 A/s`（1 mA、59 µs），每拍磁链噪声
   `σ_s·Δt ≈ 1.2e-3 A`；在 ~1 s 的拟合窗上随机游走 `σ_s√(Δt·τ) ≈ 0.17 A`，
   去掉窗均值后约 0.1 A，对 `ρ=4.04 A` 给出 ~1.4°，与实测 1.3° 一致。
4. **不是结构错误**：合成数据（无噪声、无模型误差）上整条链路的稳态误差
   是 0.03° 量级（单个拟合周期内）；`k` 误差只在每个拟合周期内以 `Δk·b`
   的形式出现，`b` 是 10 ms 的电流积分，本仿真里对应的 100 Hz 锯齿 <0.02°。
